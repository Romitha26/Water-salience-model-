# Water-Salience-Model

Overall this model simulates farmer perceived seasonal water adequacy to decide cultivation area in centralized and quasi-decentralized irrigation systems in Sri Lanka

## Running Analysis for Different Irrigation Systems

This script is applied to two irrigation systems (quasi-decentralized YE and centralized NJG) across three different periods (P1-P3).

### Quasi-Decentralized YE
- **Normalized Distance**: 0.2
- **Input Data Files**:
  - Period 1 (P1): `data/YE_1990_2000.csv`
  - Period 2 (P2): `data/YE_2001_2011.csv`
  - Period 3 (P3): `data/YE_2012_2020.csv`

### Centralized NJG
- **Normalized Distance**: 0
- **pond_surface_area**: 0
- **max_pond_storage**: 0
- **Input Data Files**:
  - Period 1 (P1): `data/NJG_1990_2000.csv`
  - Period 2 (P2): `data/NJG_2001_2011.csv`
  - Period 3 (P3): `data/NJG_2012_2020.csv`
